# Договорились

Telegram-бот и веб-доска: договорённости из рабочего чата команды («сделаю к пт», «беру», «давай я»)
становятся задачами с ответственным, сроком и цитатой. Модель только предлагает карточку — сохраняет человек.

```
Telegram ──► бот (aiogram) ──► Redis Streams ──► воркер: предфильтр → GigaChat → карточка в чат
                │                                                     │
                └── «✅ Да» ──► PostgreSQL ◄── FastAPI ◄── веб-доска (React)
```

## Запуск (Windows, локально)

Нужны: Docker Desktop, Python 3.12+, Node 20+. Секреты — в `.env` (шаблон: `.env.example`).

```bash
python -m venv .venv && .venv/Scripts/pip install -r backend/requirements.txt
cd web && npm install && cd ..
.venv/Scripts/python tools/run_all.py      # docker compose + бот + воркер + API :8010 + доска :5173
```

Бот в группе должен быть администратором, в @BotFather: Group Privacy → off, Bot-to-Bot Communication Mode → on
(второе нужно только для ботов-участников в тестах). Тесты: `cd backend && ../.venv/Scripts/python -m pytest`.

## Деплой на сервер и мини-апп Telegram

```bash
.venv/Scripts/pip install paramiko
.venv/Scripts/python tools/deploy.py --host <IP> --password '<root-пароль>' --migrate-db   # первый раз
.venv/Scripts/python tools/deploy.py --host <IP>                                           # обновление
```

Скрипт ставит Docker, поднимает PostgreSQL, Redis, бота, воркер, API и Caddy (HTTPS от Let's Encrypt) на
`https://<ip>.sslip.io` или на свой домен (`--domain`). Образ бэкенда — 350 МБ (`deploy/Dockerfile`).

Мини-апп: в @BotFather → `/newapp` → бот → название «Доска», описание, обложка `deploy/miniapp_cover.png`,
URL `https://<домен>/`, короткое имя, например `board`. Затем `tools/deploy.py --host <IP> --miniapp board`.
В группе `/board` даёт кнопку «Открыть доску» (`t.me/<бот>/board?startapp=…`): вход по Telegram-аккаунту, доска
видна только участникам чата (проверка подписи `initData` и `getChatMember`). В личке с ботом — кнопка меню «Доска».

## Что умеет

**В чате**
- Обещание («сделаю к пт», «беру», «давай я», «+» на просьбу) → карточка «✅ Да / ✏️ Исправить / ✖️ Не задача».
  Без «Да» ничего не сохраняется.
- «✏️ Исправить» — ответьте своими словами: «не Егор, а Андрей», «срок — суббота», «без срока»; карточку правит модель.
- «Кто сделает фронт?», «кто что берёт: фронт, бэк, преза?», «таски: 1… 2…» → карточка «Кто возьмёт?» с кнопкой
  «🙋» на каждую задачу. Взять можно кнопкой или текстом («бэк беру до чт» → после «Да» пункт отмечается сам).
- Имя в сообщении сопоставляется с участником: уменьшительные и падежи («Лёша», «Лёше» → Алексей), ник латиницей,
  «меня зовут …». Не нашёлся (или подходят двое) → карточка «Кто возьмёт?» с кнопкой «🙋 Беру».
- «Кто возьмёт?»: взять можно кнопкой, ответом на карточку («гляну сегодня вечером» — со сроком), текстом
  («я возьму продление домена» найдёт свободную «Пролонгировать домен», синонимы: логин = авторизация и т. п.)
  и кнопкой «Беру» на доске.
- «я заболел, Лёш, забери демо» → «🔁 Дима → Лёша: провести демо?»; «фронт больше не нужен» → «🗑 Удалить?»;
  «созвон отменяется» → «Отменить встречу?».
- Серия коротких сообщений одного человека («так / по релизу / я завтра / соберу / changelog») разбирается вместе.
- Права: задачу меняют, закрывают и удаляют только исполнитель, тот, кто её предложил, и автор сообщения —
  и в чате, и на доске (на доске — из мини-аппа; по ссылке из браузера только просмотр). Изменения с доски бот
  коротко пересказывает в чате.
- Сроки: «к концу месяца», «до 25 числа», «до конца следующей недели», «by Monday»; время («к 18:00», «до обеда»);
  «срочно» → 🔥 и срок сегодня; прошедшая дата — с предупреждением; на кнопках срока — даты («До пт 23.10»).
- Взяли задачу без срока — бот сразу спрашивает срок (кнопки «Сегодня / Завтра / До пт / …» или ответ текстом).
  Срок выбирает исполнитель или тот, кто предложил задачу (спросил «кто возьмёт?», попросил, поручил).
- `/delete N` — удалить задачу (с подтверждением); на доске — корзина в карточке задачи, с «Отменить».
- Встречи: «кто придёт на созвон завтра в 19?», «давайте встретимся, обсудим» → карточка «✅ Буду / 🤔 Может /
  ✖️ Не смогу» — видно, кто идёт; ответить можно и текстом на карточку («+», «не смогу»). За 15 минут — напоминание.
  На доске — отдельный раздел «Встречи» (кнопка рядом с «Обновить»): неделя полосой и день по часам.
- Бот пишет без звука; со звуком — только напоминания о сроках и встречах.
- Поручение строкой «задача - имя» («развернуть сайт - андрей») → карточка на этого человека, даже если он ещё не писал
  в чат. «Меня зовут Андрей» бот запоминает: «андрей, сделай…» найдёт этого участника.
- «Кто делает бэк?» про уже взятую задачу → «ℹ️ уже взял(а) …»; «нужно сделать мем» → «Кто возьмёт?».
- «Я доделал бэк», «фронт готов» → «✅ Готово?»; после подтверждения задача уходит в «Сделано».
- Перенос («не успею к пт, сделаю к пн», «хорошо, будет завтра») → «🔁 Перенести срок?» — срок сам не меняется.
- Напоминание ответственному за сутки до срока.
- Сбой не выглядит как «бот умер»: если сообщения ждут разбора дольше 45 с, бот пишет в чат почему
  (GigaChat не отвечает / перезапускаюсь / много сообщений), а после восстановления правит это на «✅ Снова работаю».
  `/status` — проверить вручную.
- Чат не засоряется: решённая карточка удаляется вместе с перепиской правки, а итог виден реакцией на исходном
  сообщении (🤝 — задача записана, 👌 — срок принят, ✍ — карточка поправлена, 👍 — `/done`); «Кто возьмёт?» исчезает,
  когда всё разобрано; справки («уже взял», «не понял срок») удаляются сами через полторы минуты. Для этого боту нужно
  право администратора «Удаление сообщений».

**На доске** (ссылка из `/board`): колонки «Просрочено / Ближайшие 2 дня / В работе / Сделано», поиск по переписке,
фильтр по людям, свободные задачи из «Кто возьмёт?», отчёт к чекпоинту с копированием. По клику на задачу — экран задачи:
статус, ответственный, срок, чекпоинт, переписка «задание → ответ» (обещание подсвечено), «Открыть в Telegram», история
событий, кнопки «Готово» и «Перенести срок». Ссылка на конкретную задачу: `…/?t=<токен>&task=7`.

| Команда | Что делает |
|---|---|
| `/task` (ответом на сообщение) | бот пропустил договорённость — сделать из сообщения карточку |
| `/tasks` | открытые задачи по людям |
| `/done N` | задача N выполнена |
| `/board` | ссылка на веб-доску (подписанная, 7 дней) |
| `/report [ДД.ММ]` | отчёт к чекпоинту: сделано / просрочено / в работе |
| `/checkpoint ДД.ММ` | дата чекпоинта — «к КТ», «к защите» будут означать её |
| `/forget` | удалить свои данные (с подтверждением): задачи команды остаются, имя и цитаты — «Участник» |
| `/status` | всё ли работает: задержка разбора, воркер, модель |
| `/delete N` | удалить задачу N (на доске её можно вернуть) |

Настройки в `.env`: `GIGACHAT_MODEL` (GigaChat-2-Pro), `EXTRACT_PROMPT` (v2 — прошёл RAT, v3 — ловит «ща гляну»),
`DEADLINE_ASK_DELAY_S` (0 — спрашивать срок сразу).

## Тесты

```
cd backend && ../.venv/Scripts/python -m pytest -q                 # юнит-тесты
.venv/Scripts/python tools/e2e_remote.py --host <IP>                # сквозной тест в живой группе на сервере
```

Сквозной тест нужен с тестовыми ботами-участниками (`ACTOR_BOT_TOKENS`, `TEST_CHAT_ID` в `.env`): они пишут
в группу настоящие сообщения, тест проверяет карточки, права, доску, встречи, сбои и `/forget`, потом убирает за собой.
